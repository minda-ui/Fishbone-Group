- **Display / headings / KPI values / wordmark:** **Source Serif 4** (Google Fonts) — gives reports an

- **Body / tables / labels / UI:** **Manrope** (Google Fonts).

## Reporting house-style

For any group report, dashboard or digest (internal-facing):

1. **Masthead** — white band: the fishbone **logo** + a *Fishbone Group* **wordmark** (Source Serif 4,
   deep green) on the left, a **"Private & Confidential"** classification pill on the right, a document-type
   eyebrow, and a **3px brand-green** bottom rule.
2. **Confidence tiers** — tag every fact **Verified** (live register / filed document) / **Provisional**
   (unverified lead) / **Gap** (not established). Never present Provisional as fact.
3. **Confidentiality band** at the foot — *"Private — not for onward sharing"* plus the data-boundary
   statement (public register data only; no residential address, full DOB, banking, payroll or health data;
   findings stated as **data, not conclusions**).
4. **Tone** — analytical / due-diligence register: measured, factual, **no marketing superlatives**
   ("best", "award-winning", "market-leading") unless a cited source backs them.
5. **Restyle never rewrites data** — when branding an existing report, the facts, sources and tier tags are
   preserved **byte-for-byte**; only the presentation changes, verified by re-count.

The full CSS (design tokens above, masthead, tier chips, tables, KPI tiles, timeline, confidentiality band)
is embedded in the reusable template below and in the worked example; copy from there rather than
re-deriving it.
